## Description

Tammy is local-first accounting software for Australian small businesses. Create an encrypted local workspace, set up an organisation and chart of accounts, post balanced journals, inspect the trial balance, upload and review source documents, import and reconcile bank statement transactions, prepare GST and BAS drafts, and inspect retained local activity.

Business data stays in the encrypted workspace on this Mac. Tammy does not require a cloud account and this release does not include advertising, analytics, tracking, in-app purchases, or ATO lodgement.

## Review notes

Tammy is an offline desktop application and has no remote account or demo credentials. On first launch, choose **Create encrypted workspace**, record the one-time recovery code, confirm it has been saved, and sign in with the locally created owner credentials. The reviewer can then create a fictional organisation and use the included Australian chart template.

The bundled `tammy-core` executable is supervised by Electron and serves only the authenticated loopback transport. The app does not download executable code or leave a background process running after quit.

The reporting screen is labelled **BAS draft — not lodged**. Tammy prepares local reporting information only and does not submit a BAS, company EOFY report, company tax return, ATO or SBR message in this release.

For review support contact, email `ben.ebsworth@gmail.com`. Do not send real accounting records, recovery codes, passwords, machine credentials, or keys.
