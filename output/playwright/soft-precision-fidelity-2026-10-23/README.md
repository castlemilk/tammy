# Invoice list fidelity — board 07

This first block uses the approved invoice-list reference directly. The original
board is retained byte-for-byte in reference/. The before app capture uses clean
ordinary packaged source 7aa28d4e and eight isolated synthetic invoices created
through the supported UI: four Draft, four Issued. The app viewport is 1440×1100.
The reference is a generated design concept, never runtime evidence.

The implementation separates the invoice list from edit/detail work. It adopts
the compact hierarchy, forest primary action/wordmark, flat ivory surface, single
line columns, 56px rows and restrained statuses. Search/paging/focus and explicit
financial confirmations remain. No unsupported statuses or sending are added.

After capture and actual visual comparison remain outstanding at this source
checkpoint. Passing tests alone does not establish reference fidelity. Existing
screenshots and archives are not modified.
